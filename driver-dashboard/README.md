# SV2 – Bảng điều khiển tài xế

Thư mục này chứa các màn hình nghiệp vụ tài xế, stylesheet, JavaScript, dữ liệu mẫu và tài liệu trình bày.

## Màn hình

- `driver-dashboard.html` – Bảng điều khiển tài xế
- `driver/driver-trip-create.html` – Tạo chuyến mới
- `driver/driver-trip-recurring.html` – Lịch trình lặp lại
- `driver/driver-schedule.html` – Lịch chạy
- `driver/driver-trip-detail.html` – Chi tiết chuyến xe
- `driver/driver-join-requests.html` – Yêu cầu ghép chuyến
- `driver/driver-trip-execution.html` – Điều hành chuyến đi
- `driver/driver-earnings-history.html` – Lịch sử chia sẻ chi phí
