# Gói 3 trang SV3 đã tách HTML, CSS và JavaScript

Gói này gồm các trang:

- `pages/coordinator-pickup-zone-editor.html`
- `pages/admin-system-logs.html`
- `pages/admin-platform-settings.html`

Mỗi trang có một CSS riêng trong `css/` và một JavaScript riêng trong `js/pages/`. Tất cả CSS/JavaScript dùng chung nằm trực tiếp trong `OBS/`.

Mở các trang trong thư mục `pages/`. Các liên kết quay lại trang quản lý liên quan đi về bản đầy đủ ở `../pages/` của gói SV3 chính. Những trang gốc của ứng dụng không bị di chuyển hay thay đổi.

```text
3-trang-tach-rieng/
├── OBS/
│   ├── [CSS dùng chung]
│   └── [JavaScript dùng chung]
├── css/[mỗi trang một file CSS riêng]
├── js/pages/[mỗi trang một file JavaScript riêng]
└── pages/[3 file HTML]
```
